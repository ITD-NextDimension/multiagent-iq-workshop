## 一、怎么跑这个脚本

解压讲师发的 `pre-request-check.zip`，里面按平台分了两个文件夹，**打开属于你的那个**，另一个不用管：

```text
pre-request-check/
  mac/      → macOS 和 Linux 用这个
  windows/  → Windows 用这个
```

每个文件夹里都有一个脚本和一份对应平台的网页版清单。

### macOS（和 Linux）

1. 把 `mac/workshop-precheck-mac.sh` 存到「下载」文件夹
2. 打开「终端」（聚焦搜索 `Terminal`），粘贴这一行回车：

```bash
bash ~/Downloads/workshop-precheck-mac.sh --yes
```

### Windows

1. 把 `windows/workshop-precheck-windows.ps1` 存到「下载」文件夹
2. 开始菜单搜 **PowerShell**，**右键 → 以管理员身份运行**（装 WSL 需要）
3. 粘贴这一行回车：

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\workshop-precheck-windows.ps1" -Yes
```

> ⚠️ **Windows 会要求重启一次。** 课程当天所有命令都在 **WSL 的 Ubuntu** 里敲（Lab 05 的部署脚本是
> bash，PowerShell 跑不了），所以脚本会先装 WSL2 + Ubuntu。装完它会让你重启电脑，
> 重启后在 Ubuntu 窗口里设一个用户名和密码，然后**把同一条命令再跑一遍**。这是正常流程，不是出错。

### 可选参数

| 参数 | 什么时候用 |
|---|---|
| `--yes` / `-Yes` | **推荐**：全自动，不逐项问你 |
| 不加参数 | 想知道每一步装了什么，逐项确认 |
| `--check-only` / `-CheckOnly` | 只体检，一个字节都不装 |
| `--skip-azure` / `-SkipAzure` | 暂时不装 Lab 05 的 `az` / `kubectl` |

反复运行是安全的，装到一半断了就重跑。

## 四、脚本查不了的两件事（手动，30 秒）

脚本能看到扩展装没装，**但看不到你的 GitHub 登录状态和组织策略**。Lab 02–04 全程依赖 Copilot，务必自己确认：

1. 打开 VS Code（**Windows 用户先用左下角 `><` → Connect to WSL 进入 Ubuntu**），确认**已登录 GitHub 账号**
2. 打开 Copilot Chat（`⌃⌘I` / `Ctrl+Alt+I`），确认输入框上方能切到 **Agent** 模式
3. 在 Agent 模式里随便问一句，能正常回答

> ⚠️ 切不到 Agent 模式 = 你所在 GitHub 组织的策略把它关掉了。**这是唯一必须提前一天发现的问题**，
> 当天再找管理员来不及。→ 找组织的 GitHub 管理员开启；或者装 Claude Code / Cursor，
> Lab 02–04 用它们完成（MCP 协议完全一样，只是注册配置文件不同，讲义里两种写法都给了）。

## 五、四个最常见的坑

1. **Windows 把课程命令敲在 PowerShell 里**
   课程里的 `.sh` 脚本在 PowerShell 跑不了。**只有这个体检脚本用 PowerShell**，
   上课的所有命令都在 **WSL 的 Ubuntu** 里敲。
   → VS Code 要用左下角 `><` → **Connect to WSL** 打开项目，否则用的是 Windows 侧的 Python。

2. **Windows 装完 WSL 没重启就继续**
   症状是脚本反复说"未安装发行版 Ubuntu"。
   → 必须重启一次，并在 Ubuntu 窗口里设好用户名密码，然后重跑同一条命令。

3. **macOS 没装 Homebrew**
   脚本在 macOS 上靠它装东西，没有就只能报 FAIL。
   → 先跑一次官网那条命令：
   `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/brew/HEAD/install.sh)"`

4. **公司电脑的网络策略**
   代理 / VPN / 证书拦截会让 `pip` 和 `curl` 直接失败，这是最常见的 NOT-READY 原因。
   → 换个网络（手机热点最快）重跑一次就能判断是不是网络问题。

## 六、自助排障顺序

按这个顺序试，**每一档都能让你完整跟完课**：

| 档 | 做法 | 影响 |
|---|---|---|
| 1 | 重跑脚本（加 `--yes` / `-Yes`），按每条 FAIL 的「→ 修复：」处理 | 无 |
| 2 | 换个网络（手机热点）再跑一次 | 无 |
| 3 | 装 Docker Desktop —— 课上用容器跑，完全不依赖本机 Python | Lab 01/02 改代码要在容器外做 |
| 4 | 把报告文件发到班级群，讲师课前帮你看 | 无，但要赶在开课前 |
| 5 | 现场和同学结对，两人一台机器 | 无 |
